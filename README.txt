KANISH R T RESPONSIVE PORTFOLIO
=================================

Files:
- index.html
- style.css
- script.js
- profile.jpg
- resume.pdf

Responsive behavior:
- Desktop/laptop: two-column hero, desktop navigation, multi-column cards.
- Tablet: tighter spacing and resized profile image.
- Mobile: one-column hero, compact typography, stacked buttons, and floating bottom navigation.
- Profile photo: circular image with animated gradient ring and soft glow.
- Certificates: click a certificate to open fullscreen; close with X, outside click, or Escape.

IMPORTANT:
Keep your existing certificate-images/ folder beside index.html.
The HTML expects these files:
- certificate-images/frontend-react-js.png
- certificate-images/java-with-sql.png
- certificate-images/niit-html5-programming.png
- certificate-images/niit-programming-in-java.png
- certificate-images/tally-essential-level-1.png
- certificate-images/typewriting-english.png

To run:
1. Keep all files in the same portfolio folder.
2. Open index.html in Chrome.
3. For GitHub Pages, upload the complete folder/repository.
